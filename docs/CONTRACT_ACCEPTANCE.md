## 4. 2단계 검수 시연 순서 (약 10분, 테스트 URL)

1. 본사: 운영 관리 → 현장 등록(위치·반경) → 직원 계정 발급
2. 현장소장 휴대폰: 첫 로그인(비밀번호 변경) → 출근(위치 동의) → 본사 작업지시 ‘확인했어요’ → 현장 보고(지시 연결·사진) → 작업지시 ‘다 했어요’(작업량·사진)
3. 현장소장: 근태 수정 요청(예: 퇴근 누락)
4. 본사: 대표 대시보드 ‘처리 대기’ → 지시·확인에서 작업지시 완료 확인 / 보고 보완 요청 / 근태 요청 승인 → 출퇴근 현황에 ‘현장 요청 승인’ 이력
5. 현장소장: 보완 요청 보고에 사진 보완 → 본사 확인

## 4-1. 3단계 검수 시연 추가분 (약 5분)

1. 현장소장 휴대폰: ‘오늘 작업 인원 알리기’(팀·인원·단체 사진) + 노무 공수 보고
2. 본사: 대표 대시보드 ‘처리 대기 → 인건비 확인 필요 현장’ → 투입·인건비에서 추정 vs 실제·표시 확인 → 팀 단가 입력 → CSV
3. 발주처: 포털에서 ‘견적 문의’ 또는 ‘주문 요청’(품목·수량)
4. 본사: ‘처리 대기 → 회신 안 한 고객 요청’ → 요청함에서 검토 시작 → 회신 → 발주처 포털에 ‘회신 완료’

## 4-2. 실제 자료 이관 순서 (태강 파일 수령 후, 반나절)

1. 본사: 운영 관리 → 진행 중 현장 등록(원 계약·실행예산·담당·위치·공정 단계)
2. 자료 이관·점검 → 양식 5종 내려받기 → 태강 공무가 엑셀에 붙여넣기 → ‘CSV’로 저장
3. 팀 단가 → 기성·입금 → 변경공사 → 출력 이력 → 원가 순서로 올리기 (오류는 행 번호대로 고친 뒤 다시)
4. 현장별 준비 점검이 ‘빠짐 0’인지 확인 → 운영 관리에서 잔여예상원가 재추정
5. 대표 확인: 현장 손익·기성/미수·투입 인건비가 태강 장부와 맞는지 (잘못 넣었으면 7일 안 ‘가져오기 취소’)

## 5. 검수 전 확인 필요 (계약서 ‘최종 검수 전 우선 확인할 자료’ 대응)

- 태강 현장 1~2건 실제 작업 흐름 테스트 데이터 (현장·공정 단계·직원·협력업체 팀)
- 근태 위치정보 고지·처리 근거·내부규정, 관리자별 접근권한 (별지 제5호 ‘적용 확인’ 체크)
- 현장별 원가분류·**팀별 투입단가(직영/외주 지급 방식 포함)**·기성·변경공사 규칙과 담당자
- 견적 문의·주문 요청 회신 담당자
- 직원 실사용 피드백, 본사 승인 담당자, 대표자 최종 검수
